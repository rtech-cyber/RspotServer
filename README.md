# R-SpotServer — Logiciel de Gestion de Hotspot WiFi MikroTik (Gratuit)

**Vends et gère l'accès WiFi de ton hotspot en toute simplicité.** R-SpotServer est une solution complète de gestion de hotspot WiFi pour routeurs **MikroTik**, pensée pour les cybercafés, hôtels, WiFi Zones et opérateurs de connexion internet en Afrique et ailleurs. Génère des tickets de connexion, suis tes ventes en temps réel, gère plusieurs points de vente, et pilote tout depuis une interface moderne — sans connaissances techniques poussées.

> **Cherches-tu une alternative à MIKHMON ?** R-SpotServer est basé sur MIKHMON et l'étend largement : comptabilité intégrée, distribution multi-PDV, monitoring réseau, alertes WhatsApp, sauvegarde automatique et bien plus.

## 🔑 Identifiants de connexion par défaut

```
Utilisateur : admin
Mot de passe : root
```

> ⚠️ **Change immédiatement ce mot de passe après ta première connexion** (Paramètres > Sessions). Ne jamais laisser les identifiants par défaut sur une installation utilisée en production — c'est la première chose qu'un attaquant essaiera.

## ✨ Fonctionnalités principales

- **Vente et génération de vouchers WiFi** (unitaire ou en masse, avec QR code)
- **Gestion multi-routeurs MikroTik** depuis une seule interface
- **Analytics et rapports de vente** — tendances, projections, comptabilité intégrée
- **Espace Distributeur** — attribution de lots de tickets à des points de vente, suivi de stock en temps réel
- **Comptabilité** — registre, bilan, dépenses récurrentes, objectifs mensuels
- **Monitoring réseau** — vue flotte multi-routeurs, appareils connectés, alertes CPU/mémoire
- **Alertes WhatsApp** — récap quotidien automatique, notification de panne
- **Sauvegarde automatique** et export/restauration
- **Terminal SSH intégré** pour administrer le routeur directement

## 🖥️ Installation

Pas besoin d'Apache, MySQL ou XAMPP. R-SpotServer embarque tout ce qu'il faut (serveur PHP portable + SQLite) dans un exécutable Windows autonome.

1. Télécharge la dernière version depuis [Releases](../../releases)
2. Dézippe où tu veux
3. Lance `windows/CreateShortcut.bat` une fois
4. Utilise le raccourci créé sur le Bureau

Voir [`windows/README.md`](windows/README.md) pour les instructions détaillées.
